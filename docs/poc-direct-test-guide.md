# 지출 첨부검사 PoC 직접 테스트 가이드

> 이 가이드는 실제 지출결의를 상신하지 않고 열람 화면에서 검사 기능만 확인하는 절차임.
> `examples/poc-expense-rules.json`은 가상 규칙이므로 운영 판정에 사용하면 안 됨.

## 1. 파일럿 자동 설치

1. 탐색기에서 `scripts\install-pilot.cmd` 실행
2. 자동으로 열린 Chrome 확장 관리 화면에서 **개발자 모드** 활성화
3. **압축해제된 확장 프로그램을 로드합니다** 선택
4. 아래 폴더 선택

   `%LOCALAPPDATA%\TTAExpenseChecker\app`

5. 설치된 확장 ID가 `lmkejmofkdcjnfcnmjgekbfippdklaco`인지 확인

Edge를 사용할 경우 `edge://extensions`에서 같은 절차로 설치함.

## 2. 자동기동 확인

설치 직후 파서와 Ollama가 무창으로 실행되며, 이후 Windows 로그인 때마다 자동 시작함.
상태를 수동으로 다시 확인해야 할 때만 아래 파일을 실행함.

`scripts\poc-start.cmd`

다음 문구가 나오면 정상임.

```text
정상입니다. 이 창을 열어 둔 채 전자결재 화면에서 첨부검사를 실행하세요.
주소: http://127.0.0.1:11435
```

실행기는 설치된 Ollama도 함께 확인함. Ollama가 꺼져 있으면 고정 확장 ID만 접근할 수 있도록
자동 기동하며, 이미 다른 접근 설정으로 실행 중이면 재시작 여부를 물음. AI 검토가 필요하면 `Y`를 선택함.

자동 설치 후에는 검사 중 검은 창을 열어 둘 필요가 없음.

## 3. 가상 PoC 규칙 적용

1. Chrome 확장 아이콘 우클릭 → **옵션**
2. **지출유형별 첨부 규칙** 입력란 찾기
3. `examples\poc-expense-rules.json`의 전체 내용을 복사해 붙여넣기
4. 규칙 검증 후 저장

가상 규칙은 제목에 `지출`이 포함된 화면에서 다음 파일명을 검사함.

| 파일명 포함 문구 | 판정 |
|---|---|
| 견적서 또는 견적 | 없으면 차단 권고 |
| 거래명세서 또는 거래명세 | 없으면 경고 |
| 세금계산서 또는 전자세금계산서 | 없으면 차단 권고 |

## 4. 전자결재 화면에서 검사

1. 실제 데이터 유출을 피하기 위해 테스트 가능한 지출결의 열람 화면을 사용
2. 브라우저 툴바의 확장 아이콘 클릭
3. **지출 첨부 전체 검사** 실행
4. 첨부 자동 읽기에 실패한 파일은 결과창의 **검사불가 파일 직접 선택** 클릭
5. PC에 저장한 해당 첨부파일을 선택

## 5. 확인할 결과

- 필수 파일명이 없으면 `차단` 또는 `경고`가 표시되는지 확인
- PDF/HWP/HWPX/XLS/XLSX/DOCX에서 텍스트가 추출되는지 확인
- 문서에서 금액·날짜·사업자번호·서명 단서가 표시되는지 확인
- 결의금액과 첨부문서 금액이 다르면 불일치 경고가 표시되는지 확인
- 스캔 PDF, 암호 또는 DRM 문서는 검사불가로 표시되는지 확인

AI 연결 없이도 위 규칙 검사는 동작함. 로컬 AI 의미 검사는 Ollama를 별도로 연결했을 때만 추가됨.

## 6. PoC 종료 및 원상복구

1. `scripts\uninstall-pilot.ps1` 실행
2. `chrome://extensions`에서 확장을 끄거나 제거
3. 확장 옵션의 가상 규칙은 확장 제거 시 함께 삭제됨

이 PoC는 지출결의 상신 버튼을 실제로 차단하지 않으며 검사 결과만 화면에 표시함.
